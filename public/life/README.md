# Life photos

Drop image files (`.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`, `.gif`) into this
folder and they'll appear automatically on the `/life` page — no code changes.

- Name them `1.jpg`, `2.jpg`, `10.jpg`, … to control the display order
  (they sort in natural numeric order).
- The filename (dashes/underscores → spaces) is used as the image `alt` text,
  so `golden-hour-goa.jpg` → alt "golden hour goa".

iCloud share links won't work here — export the actual image files from Photos
(drag them out, or use Share → Save Image / Export Unmodified Original) and copy
them into this folder.
