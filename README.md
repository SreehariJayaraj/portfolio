# Portfolio Blog

This is my personal portfolio + blog built using the Vercel blog starter template, customized to fit my needs.

The base template is taken from Vercel’s official examples.

## ✨ Features

- MDX and Markdown support
- SEO optimized (sitemap, robots, JSON-LD schema)
- RSS Feed
- Dynamic Open Graph images
- Syntax highlighting for code blocks
- Tailwind CSS v4
- Vercel Speed Insights / Web Analytics
- Geist font

## 📦 Getting Started

You can use this template directly from Vercel.

### One-Click Deploy

Deploy the example using Vercel:

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/vercel/examples/tree/main/solutions/blog&project-name=blog&repository-name=blog)

---

### Clone and Run Locally

You can bootstrap the project using `create-next-app`:

```bash
pnpm create next-app --example https://github.com/vercel/examples/tree/main/solutions/blog blog
